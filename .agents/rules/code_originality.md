# Codebase Originality & Integrity

- **100% Original Code**: All source code in this project must be strictly authored from scratch.
- **No Third-Party Snippets**: Do NOT copy code blocks, functions, algorithms, or logic from external open source repositories or other developers.
- **API Usage Only**: Third-party crates in `Cargo.toml` are to be used strictly via their standard public APIs. Do not copy internal code or vendored implementations.
- **Design from First Principles**: Every feature, UI element, and architectural pattern is custom-tailored to Proteus.
