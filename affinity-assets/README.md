## 2. Dynamic DPI Resolution Adaptation Guidelines

| Scale Factor | Screen Density | Grid Size | Stroke Width | Primary Application |
|---|---|---|---|---|
| **100% (1.0x)** | 96 DPI | 24×24 px | 1.75 px | Standard 1080p Desktop Displays |
| **125% (1.25x)** | 120 DPI | 30×30 px | 2.18 px | Standard Windows 11 Laptops |
| **150% (1.5x)** | 144 DPI | 36×36 px | 2.62 px | 2K QHD (1440p) Screens & Tablets |
| **200% (2.0x)** | 192 DPI | 48×48 px | 3.50 px | 4K UHD & Apple Retina Displays |

Because each icon utilizes `stroke="currentColor"` and vector curves, they render with 0 raster pixelation across any custom zoom level, high-contrast mode, or dark/light theme switch.

## 4. Affinity Designer Workflow & Export

1. Open `Proteus_Design_System_Master.svg` in Affinity Designer.
2. Edit shapes, colors, or stroke curves in the **Vector Persona**.
3. In the **Export Persona** (Slice Tool):
   - Slices are pre-configured to export SVGs directly into `project/assets/` and `affinity-assets/icons/`.
   - PNG slices automatically generate 1x, 2x, and 3x scale variants for mobile and desktop.
