# Keyboard Shortcuts

## General

| Shortcut | Action |
|----------|--------|
| Ctrl+N | New project |
| Ctrl+S | Save |
| Ctrl+I | Import |
| Escape | Deselect |

## Designer

| Shortcut | Action |
|----------|--------|
| Delete/Backspace | Delete widget |
