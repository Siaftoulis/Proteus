# Designer Mode

> Visual CRM layout builder.

## Free vs Grid
- **Free**: pixel-precise positioning
- **Grid**: 20px snap, column guides

## Actions

| Action | How |
|--------|-----|
| Add | Drag from palette |
| Select | Click |
| Move | Drag body |
| Resize | Edge/corner handle |
| Delete | Delete/Backspace |

## Widgets
Table, Chart, Text, Form, Image, Container, Button, Input, Tabs
