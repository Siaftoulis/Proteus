# Getting Started

## Install
1. Download from website
2. Run installer
3. Launch

## First Project
1. Click **New Project**
2. Add widgets from palette (Designer Mode)
3. Define logic (Flow Mode)
4. Auto-save handles the rest

## Free vs Business

| | Free | Business |
|--|------|----------|
| Users | Up to 3 | Unlimited |
| Cost | EUR 0 | From EUR 10/mo |
