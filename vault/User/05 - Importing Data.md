# Importing Data

## Supported

| Format | Extension | Notes |
|--------|-----------|-------|
| CSV | .csv | Comma/semicolon/tab |
| Excel | .xlsx | Multiple sheets |
| SQLite | .db | All tables |

## How

1. Click **Import**
2. Select file
3. Auto-detects column types (Text, Number, Date, Boolean)
4. Creates Table widget with data
