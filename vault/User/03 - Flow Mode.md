# Flow Mode

> Visual node-based logic.

## Nodes

| Type | Color | Function |
|------|-------|----------|
| Trigger | Green | Entry point |
| Action | Blue | Execute operation |
| Condition | Orange | If/else |
| Gate | Purple | AND/OR |

## Building

1. Drag **Trigger** onto canvas
2. Add **Action** / **Condition** nodes
3. Connect handles (source -> target)
4. Configure in properties panel
